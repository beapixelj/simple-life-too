# Simple Life Too (SLT) Protocol

Simple Life Too (SLT) is a proposed decentralized digital currency.

## Core Parameters

- Maximum supply: 21,000,000 SLT
- Consensus: Proof-of-Work
- Mining algorithm: SHA-256
- Target block time: 10 minutes
- Initial block subsidy: 50 SLT
- Halving interval: 210,000 blocks
- Smallest unit: slatoshi
- 1 SLT = 100,000,000 slatoshi
- Premine: 0
- Founder allocation: 0
- Mining: permissionless
- Full nodes: permissionless
- Wallet: self-custody
- Founder master key: none

This document is a working protocol specification and may be refined during development and testnet testing.
